📚 المكتبة التعليمية الشاملة للغات البرمجة

الدرس 1: المتغيرات وأنواع البيانات (Variables)

المتغيرات هي أماكن في الذاكرة لتخزين البيانات. نستخدم const للقيم الثابتة و let للقيم المتغيرة.

const siteCreator = "Gedo"; // نص ثابت let userPoints = 100; // رقم متغير let isLogged = true; // قيمة منطقية userPoints += 50; // زيادة النقاط console.log("مرحباً " + siteCreator + "، نقاطك الآن: " + userPoints);

الدرس 2: الدوال (Functions) والعمليات المنطقية

الدالة هي كتلة برمجية تنفذ مهمة محددة عند استدعائها، مما يمنع تكرار الكود.

function checkDiscount(price) { if (price >= 500) { return "حصلت على خصم 20%! السعر الجديد: " + (price * 0.8); } else { return "السعر النهائي: " + price; } } console.log(checkDiscount(600));

الدرس 3: المصفوفات والحلقات التكرارية (Arrays & Loops)

تُستخدم المصفوفات لتخزين قائمة عناصر، والحلقات للمرور عليها تلقائياً.

let languages = ["HTML", "CSS", "JavaScript", "Python"]; for (let i = 0; i < languages.length; i++) { console.log("اللغة رقم " + (i + 1) + ": " + languages[i]); }

⚠️ الأخطاء الشائعة في JavaScript وشرحها العميق:

1. التعديل على ثابت (TypeError): محاولة تغيير قيمة متغير تم تعريفه بـ const يؤدي لتوقف البرنامج فوراً. الحل: استخدم let لأي قيمة ستتغير.

2. استخدام = بدل === في الشروط: كتابة if (x = 5) تقوم بتعيين الرقم 5 داخل x بدلاً من فحصه. استخدم دائماً === للمقارنة الدقيقة بين القيمة والنوع.

3. استدعاء عناصر HTML قبل تحميلها (Null Error): محاولة الوصول لعنصر عبر document.getElementById في أعلى الصفحة قبل رسم العنصر يعطي نتيجة null.

📝 ملخص لغة JavaScript:

هي لغة التفاعل والذكاء في المتصفح. مسؤولة عن معالجة البيانات، التحكم في عناصر الصفحة، والتواصل مع الخوادم.

الدرس 1: أساسيات بايثون والمتغيرات

تتميز بايثون بسهولة قراءتها وعدم حاجتها لفواصل منقوطة أو أقواس معقوفة، بل تعتمد على المسافات البادئة (Indentation).

student_name = "أحمد" grade = 95.5 passed = True print(f"الطالب {student_name} حصل على درجة {grade}")

الدرس 2: القوائم والشروط (Lists & Conditions)

تُستخدم القوائم لحفظ البيانات المتعددة والتعامل معها بمرونة عالية.

cart = ["لابتوب", "ماوس", "لوحة مفاتيح"] if "لابتوب" in cart: print("يوجد جهاز لابتوب في سلة المشتريات!") for item in cart: print("المنتج:", item)

⚠️ الأخطاء الشائعة في Python وشرحها العميق:

1. خطأ المسافات البادئة (IndentationError): بايثون صارمة جداً في المسافات بعد جملة if أو for. أي مسافة زائدة أو ناقصة توقف البرنامج.

2. دمج نص مع رقم (TypeError): محاولة جمع نص ورقم مباشرة مثل "العمر: " + 20 تسبب خطأ. يجب تحويل الرقم لنص باستخدام str(20).

📝 ملخص لغة Python:

أقوى لغة في الذكاء الاصطناعي، تحليل البيانات، وتطوير المواقع الخلفية (Backend) بفضل بساطتها ومكتباتها الضخمة.

الدرس 1: الهيكل الأساسي والوسوم (Tags)

HTML هي الهيكل العظمي لأي موقع ويب، وتتكون من وسوم فتح وإغلاق.

<!DOCTYPE html> <html> <head> <title>موقع جدو</title> </head> <body> <h1>عنوان رئيسي</h1> <p>فقرة نصية توضيحية للمحتوى.</p> </body> </html>

الدرس 2: النماذج والمدخلات (Forms & Inputs)

تُستخدم لجمع البيانات من المستخدمين مثل تسجيل الدخول.

<form> <input type="text" placeholder="اسم المستخدم" required> <input type="password" placeholder="كلمة المرور"> <button type="submit">دخول</button> </form>

⚠️ الأخطاء الشائعة في HTML وشرحها العميق:

1. نسيان إغلاق الوسوم: فتح وسم <div> دون إغلاقه بـ </div> يؤدي لتداخل العناصر وانهيار تصميم الصفحة بالكامل.

2. تكرار نفس الـ ID: السمة id يجب أن تكون فريدة لعنصر واحد فقط في الصفحة، وتكرارها يربك أكواد JavaScript.

📝 ملخص لغة HTML:

هي لغة ترميز وليست لغة برمجة؛ وظيفتها بناء الهيكل وتنظيم المحتوى (نصوص، صور، روابط، جداول) في الصفحة.

الدرس 1: الألوان والخطوط ونموذج الصندوق (Box Model)

CSS هي المسؤولة عن تجميل الموقع وتنسيق الألوان والأحجام والمسافات.

.card { background-color: #1e293b; color: white; padding: 20px; /* مسافة داخلية */ margin: 15px; /* مسافة خارجية */ border-radius: 10px; /* حواف دائرية */ }

الدرس 2: التخطيط المرن (Flexbox)

أهم أداة في CSS لمحاذاة العناصر وتوزيعها بمرونة على جميع الشاشات.

.navbar { display: flex; justify-content: space-between; align-items: center; }

⚠️ الأخطاء الشائعة في CSS وشرحها العميق:

1. نسيان الفاصلة المنقوطة (;): عدم وضع فاصلة منقوطة في نهاية كل خاصية يعطل الخاصية التي تليها مباشرة.

2. عدم استخدام box-sizing: border-box: بدون هذه الخاصية، إضافة padding تزيد من عرض العنصر الفعلي وتكسر تناسق الصفحة.

📝 ملخص لغة CSS:

هي لغة التنسيق البصري التي تحول الهيكل الجامد إلى تصميم عصري متجاوب مع الهواتف والحواسيب.
